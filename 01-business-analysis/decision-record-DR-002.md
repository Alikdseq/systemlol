## Контекст

```
- Этап 1 без 1С (DR-001)

```

## Вопрос

```
Процент начисления; один баланс на 4 точки; имя и бюджет клиента.
```

## Варианты

```
Начисление: 10% от суммы чека (выбрано) vs иное.
Баланс: один на сеть (выбрано) vs раздельный по магазинам.
Имя/бюджет: неизвестны — не выдумывать.
```

## Решение

```
Выбрано:
- начисление: 10% от суммы чека (bonus = floor(сумма * 10 / 100), целое)
- один бонусный счёт на все 4 магазина
- имя клиента и бюджет: unknown, этап 1 не блокируют
Кто решил: CEO 2026-08-17
```

## Следствия

```
LoyaltyRule seed = 10%. Админ может изменить позже; история старых операций не пересчитывается.
Store в операциях — аналитика, не отдельные кошельки.
```
