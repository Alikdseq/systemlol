PROJECT: clothing-loyalty

## Контекст

```
- 4 магазина одежды, 1С как касса без клиентов
- Нужна бонусная лояльность по телефону, 1 бонус = 1 руб при списании
- CEO спросил: делать всё в админке/сервисе или интегрировать 1С для автоматизации
```

## Вопрос

```
Что решаем: контур этапа 1 — без обмена с 1С или ждать 1С и делать автосумму чека.
```

## Варианты

```
A: Этап 1 — отдельный сервис (касса кассира + админка). 1С не трогаем. Кассир вводит сумму чека руками. Списание: кассир зеркалит скидку в 1С. Интеграция 1С — этап 2.
B: Сначала обследование 1С (конфигурация, доступ), затем обмен суммы чека в must этапа 1. Сервис тот же, плюс адаптер.
C: Лояльность внутри 1С, без отдельного сервиса.
```

## Решение

```
Выбрано: A
Почему: CEO 2026-08-17: этап 1 без 1С.
Кто решил: CEO
```

## Следствия

```
Что меняется в работе: DEVELOPMENT только сервис лояльности. Обмен 1С не в этапе 1.
Риски, которые принимаем: двойной ввод; рассинхрон скидки 1С vs списание.
Что сознательно не делаем: обмен 1С, замена кассы, mobile покупателя.
Дополнительно CEO: начисление 10% от суммы чека; один баланс на 4 магазина; имя клиента и бюджет неизвестны — не блокируют этап 1.
```
