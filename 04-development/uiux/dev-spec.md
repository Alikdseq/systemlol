PROJECT: clothing-loyalty  
TASK: TASK-001  
AUTHOR: UI/UX Designer  
DATE: 2026-08-17  
PLATFORM: web (кассир на ПК/планшете у кассы 1С; админ — браузер)

Данные только из architecture/api-spec. 1С на экранах не рисуем. Списание: явно сказать кассиру сумму скидки для 1С.

---

## Flows

### FLOW-CASHIER-ACCRUAL (M1, M2)

1. Кассир залогинен, видит свой магазин (не выбирает каждый раз, если привязан).
2. Поле «Телефон» + Найти.
3. **Найден:** карточка: телефон, баланс, кнопки Начислить / Списать.
4. **Не найден (empty):** «Клиент не найден» + Создать.
5. Создать → карточка баланс 0 (M2).
6. Начислить: поле «Сумма чека, руб» (как в 1С) → подтверждение «Будет начислено N бонусов» (N из правила) → Успех: новый баланс.
7. Если правило % не задано: error, не молча 0 и не 1:1.

### FLOW-CASHIER-REDEEM (M3)

1. Телефон → карточка, баланс виден.
2. Списать: сумма чека + сколько бонусов списать.
3. Сервер считает остаток к оплате живыми.
4. Success: «Списано X бонусов. В 1С пробейте скидку X руб. К оплате живыми: Y руб.»
5. Если X > баланса или X > чека — error, баланс не меняется (E1).

### FLOW-GUEST (M4)

1. Покупатель не дал телефон → кассир не открывает лояльность. Нет кнопки «гость». Продажа только в 1С.

### FLOW-ADMIN-CLIENT (M5)

1. Поиск по телефону / список (пагинация).
2. Карточка: баланс, история (дата, тип, сумма чека, бонусы, магазин, кассир).

### FLOW-ADMIN-ADJUST-RULE (M6)

1. Корректировка: delta + обязательный комментарий → success в журнале.
2. Правило начисления: поле % → сохранить. Подсказка: «1 бонус = 1 руб при списании. Это поле — сколько % чека уходит в бонусы.»

## Dev-spec (кратко)

**Телефон:** ввод 10–11 цифр; нормализация на сервере; ошибка «не похоже на телефон».

**Сумма чека:** руб, > 0, 2 знака.

**Начислить:** disabled пока нет суммы; показываем preview N если % известен, иначе «задайте % в админке».

**Списать:** preview «скидка в 1С = X, живыми Y»; submit disabled если X=0.

**Идемпотентность:** одна кнопка, spinner, не двойной click (disable until response).

**Кассир не видит:** полный реестр, правило %, adjust, чужие магазины.

**Админ:** фильтр магазин, дата с–по.

Копирайт ошибок:

- 409 redeem: «Недостаточно бонусов. Баланс: B»
- 400 redeem > чека: «Нельзя списать больше суммы чека»
- 422 accrual: «Не задан процент начисления. Админ должен указать правило»
- 409 duplicate phone create: открыть существующего
