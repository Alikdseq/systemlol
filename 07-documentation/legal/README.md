# Правовые тексты Q Premium (клиентский пакет)

Канонические файлы, которые отдаёт приложение: `04-development/qpremium/backend/legal/documents/`. Эта папка — копия для Заказчика.

| Документ | Закон | Назначение |
|----------|--------|------------|
| `privacy-policy.md` | 152-ФЗ ст. 18.1 | Политика обработки ПДн (публикуется) |
| `consent-personal-data.md` | 152-ФЗ ст. 9 | Согласие на обработку (хэш в БД) |
| `consent-advertising.md` | 38-ФЗ ст. 18 | Согласие на рекламу в Telegram (отдельная галочка) |
| `consent-program-rules.md` | оферта программы | Принятие правил Mini App |

Версия текстов: **v2.0** (14.09.2026).

## Что было не так в v1.0

Однострочники в `settings.py` («согласен с политикой оператора») **не** являются согласием по ст. 9 152-ФЗ: не назван оператор, состав данных, цели, срок, трансграничная передача в Telegram, способ отзыва. Реклама была смешана с «информационными сообщениями» и не отделяла сервисные уведомления о баллах (38-ФЗ). Политика как документ отсутствовала.

## Обязательно заполнить до production

В `.env` / `.env.prod`:

```
OPERATOR_LEGAL_NAME=
OPERATOR_INN=
OPERATOR_OGRN=
OPERATOR_ADDRESS=
OPERATOR_EMAIL=
OPERATOR_PHONE=
OPERATOR_PD_CONTACT=
```

Пока поля пустые, в текстах стоит пометка «не указано оператором». Такой документ **нельзя** считать опубликованной политикой.

После заполнения — перезапуск backend (тексты подставляются при старте).

## Что делает Заказчик сам (не разработчик)

1. Подставить реквизиты юрлица / ИП.
2. Подать уведомление в Роскомнадзор (ст. 22 152-ФЗ), если нет исключения.
3. Утвердить внутренние акты по защите ПДн (ст. 18.1).
4. Держать базу на сервере в РФ (ст. 19).
5. Маркировать рекламные рассылки («Реклама.») и исполнять ОРД/erid, если конкретная рассылка — интернет-реклама.
6. Юридическая проверка своей компанией / юристом перед сдачей в Роскомнадзор. Пакет закрывает структуру требований закона; это не замена консультации по конкретной организационно-правовой форме.

## Как видит клиент

Регистрация: отдельные галочки правил, ПДн+политика, реклама (опционально) с полным текстом в диалоге.  
Профиль: отзыв рекламы в один клик.  
API: `GET /api/v1/legal`, `GET /api/v1/legal/{privacy|personal-data|advertising|program-rules}`.
